# roteiro-reels

Skill do Claude que cria roteiros de vídeos curtos (Reels, TikTok, YouTube Shorts) para qualquer nicho: gancho, falas, direção visual e CTA em tabela pronta para gravar.

## Instalação rápida (Claude Code)

Cole esta frase no Claude Code e ele instala para você:

> Instala a skill deste repositório: https://github.com/lucalves3/skill-de-roteiro-reels

Ele clona o repositório em `~/.claude/skills/roteiro-reels`. A skill passa a valer normalmente a partir da próxima sessão.

## Como instalar manualmente

**Claude Code**

```bash
git clone https://github.com/lucalves3/skill-de-roteiro-reels.git ~/.claude/skills/roteiro-reels
```

No Windows, a pasta é `C:\Users\<seu-usuario>\.claude\skills\roteiro-reels`.

**Claude.ai**

Baixe o repositório como ZIP (Code → Download ZIP), compacte a pasta com o `SKILL.md` na raiz e envie em Configurações → Capacidades → Skills.

## Como usar

Basta pedir naturalmente:

- "Faz um roteiro de Top 5 ferramentas de IA para criar roteiros"
- "Preciso de 3 ideias de Reels sobre investimentos para iniciantes"
- "Transforma esse texto em roteiro de 30 segundos"

## O que a skill entrega

- Gancho nos primeiros 3 segundos
- Blocos de fala curtos, com duração estimada
- Coluna de direção visual
- CTA único e específico
- Sugestão de legenda e hashtags
